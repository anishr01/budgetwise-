💰 BudgetWise — AI Driven Expense Tracker and Budget Advisor
📌 Overview

BudgetWise is a Java Full Stack AI-powered expense tracking application designed to help users manage their finances efficiently. It allows users to track income and expenses, set budgets, visualize spending patterns, and receive intelligent financial recommendations.

The system combines traditional expense tracking with AI-driven insights to improve financial decision-making and savings habits.

🚀 Features
🔐 User Authentication (Login/Signup)
💸 Income & Expense Tracking
📊 Interactive Dashboard (charts & reports)
🧠 AI-Based Expense Categorization
📅 Monthly Budget Planning & Alerts
🤖 Smart Budget Advisor (AI Recommendations)
🔎 Transaction History & Filtering
📈 Spending Trend Analysis

⚙️ Installation & Setup
1️⃣ Clone Repository
git clone https://github.com/your-username/BudgetWise.git
cd BudgetWise
2️⃣ Backend Setup (Spring Boot)
cd backend
mvn spring-boot:run
3️⃣ Database Setup
Create MySQL database
Import SQL file from /database folder
Update application.properties:
spring.datasource.url=jdbc:mysql://localhost:3306/budgetwise
spring.datasource.username=root
spring.datasource.password=yourpassword
4️⃣ Frontend Setup
cd frontend
open index.html
5️⃣ AI Module (Optional)
cd ai-module
pip install -r requirements.txt
